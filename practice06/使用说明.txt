========================================
Practice 06: 技能管理 Agent - 使用说明
========================================

【重要】正确的使用步骤：

方法1：使用批处理文件（推荐）
--------------------------
1. 双击运行 start.bat 文件
2. 等待程序启动，看到 "👤 你:" 提示
3. 输入你的问题，例如：
   帮我写个关于五一放假的通知

方法2：命令行启动
--------------------------
1. 打开 PowerShell 或 CMD
2. 输入: cd practice06
3. 输入: python agent_with_skills.py
4. 等待看到 "👤 你:" 提示
5. 输入你的问题

【错误示范】
--------------------------
❌ 不要直接在 PowerShell 输入中文，像这样：
   PS E:\trae\zhou4\practice06> 帮我写个关于五一放假的通知
   
   这会导致错误：
   "无法将"帮我写个关于五一放假的通知"项识别为 cmdlet..."

✅ 正确的做法是先运行 python 程序，然后在程序里输入

【测试用例】
--------------------------
启动程序后，可以输入：

1. 查看技能列表：
   /skills

2. 测试 notice 技能（不说部门）：
   帮我写个关于五一放假的通知
   
   预期输出：以 "XX部通知" 开头

3. 测试 notice 技能（说部门）：
   我是销售部的，帮我写个关于五一放假的通知
   
   预期输出：以 "销售部通知" 开头

4. 退出程序：
   /exit

【常见问题】
--------------------------
Q: 出现 HTTP 403 错误怎么办？
A: 这是 API 密钥问题。程序会提示是否使用模拟响应，输入 y 即可看到演示效果。

Q: 中文显示乱码怎么办？
A: 程序已自动设置 UTF-8 编码，如果仍有问题，请确保使用 Windows 10/11 的 PowerShell。
