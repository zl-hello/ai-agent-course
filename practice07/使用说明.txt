========================================
Practice 07: 链式工具调用 Agent - 使用说明
========================================

【什么是链式工具调用？】
--------------------------
链式工具调用允许 LLM 执行多步骤任务，前一个工具的输出作为后一个工具的输入。

示例：
  用户说: "分析目录 ./docs 并读取第一个文件"
  
  步骤1: 列出文件 → 得到 ["file1.txt", "file2.txt"]
  步骤2: 读取文件 → 使用 "file1.txt"
  
  结果: 返回文件内容

【正确的使用步骤】
--------------------------

方法1：使用批处理文件（推荐）
1. 双击运行 start.bat 文件
2. 等待程序启动，看到 "👤 你:" 提示
3. 输入你的问题

方法2：命令行启动
1. 打开 PowerShell 或 CMD
2. 输入: cd practice07
3. 输入: python agent_with_skills.py
4. 等待看到 "👤 你:" 提示
5. 输入你的问题

【链式工具测试用例】
--------------------------

1. 分析目录并读取文件
   输入: 分析目录 ./practice07 并读取文件
   
   预期输出:
   [链式调用] 开始执行: analyze_and_read
     [节点] list_files: 列出目录中的所有文件
       ✅ 成功
     [节点] read_file: 读取第一个文本文件
       ✅ 成功
   [链式调用] 执行完成: 2/2 成功

2. 搜索历史并总结
   输入: 搜索历史关于通知的内容并总结
   
   预期输出:
   [链式调用] 开始执行: search_and_summarize
     [节点] search_history: 搜索聊天历史
       ✅ 成功
     [节点] summarize: 生成搜索结果摘要
       ✅ 成功

3. 使用技能执行任务
   输入: 使用 notice 技能帮我写个五一放假通知
   
   预期输出:
   [链式调用] 开始执行: skill_and_execute
     [节点] load_skill: 加载技能内容
       ✅ 成功
     [节点] execute_with_skill: 使用技能上下文处理任务
       ✅ 成功
   
   XX部通知
   ...

【其他命令】
--------------------------
- /skills  - 查看可用技能列表
- /skill   - 查看当前激活的技能
- /history - 查看对话历史
- /clear   - 清空对话历史
- /exit    - 退出程序

【常见问题】
--------------------------
Q: 出现 HTTP 403 错误怎么办？
A: 这是 API 密钥问题。程序会提示是否使用模拟响应，输入 y 即可看到演示效果。

Q: 如何添加新的工具链？
A: 编辑 chained_tools.py 文件，在 _register_default_chains 方法中添加新的 ToolChain。

Q: 中文显示乱码怎么办？
A: 程序已自动设置 UTF-8 编码，如果仍有问题，请确保使用 Windows 10/11 的 PowerShell。
