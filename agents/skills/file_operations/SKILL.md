# 文件操作技能

## 功能概述

本技能提供完整的文件系统操作能力，让 Agent 能够：

- 列出目录内容
- 创建新文件
- 读取文件内容
- 重命名文件
- 删除文件

## 使用场景

- 文件管理任务
- 代码生成和保存
- 日志文件处理
- 配置文件操作

## 注意事项

- 只能操作文件，不能删除目录
- 大文件（>1MB）读取会被拒绝
- 需要适当的文件系统权限
