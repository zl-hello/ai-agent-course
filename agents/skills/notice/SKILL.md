# 通知撰写技能

## 功能概述

本技能提供专业的通知文档撰写、修改和润色服务，确保通知格式规范、内容清晰、表达准确。

## 核心规则（必须遵守）

### 标题格式要求

1. **绝对不能**以"通知"二字开头
2. **必须**冠以"XX部"的前缀
3. 正确格式：`XX部通知` 或 `XX部门通知`

**正确示例：**
- 采购部通知
- 宣传部通知
- 人力资源部通知
- 技术部通知
- XX部通知（用户未告知部门时使用）

**错误示例：**
- ❌ 通知：关于...
- ❌ 通知
- ❌ 关于...的通知

### 内容结构

1. **标题**：XX部通知（按上述规则）
2. **称呼**：（可选）各位同事/全体员工/相关部门
3. **正文**：
   - 背景说明
   - 具体要求
   - 时间安排
   - 联系方式
4. **落款**：发文部门 + 日期

## 使用场景

- 撰写会议通知
- 撰写活动通知
- 撰写政策通知
- 修改现有通知
- 润色通知文案

## 部门识别规则

1. 如果用户明确告知部门，使用该部门名称
2. 如果用户未告知部门，使用"XX部"作为占位符
3. 常见部门：采购部、宣传部、人力资源部、技术部、财务部、行政部、市场部等

## 示例

### 示例1：用户告知部门

用户：帮我写个通知，我是宣传部的，要组织周五的团建活动

输出：
```
宣传部通知

各位同事：

为增强团队凝聚力，丰富员工业余生活，宣传部定于本周五组织团建活动。具体安排如下：

一、活动时间：本周五下午14:00-18:00
二、活动地点：公司会议室及户外活动区
三、活动内容：团队游戏、交流分享、晚餐聚会
四、参与人员：宣传部全体成员

请提前安排好工作，准时参加。

宣传部
2024年X月X日
```

### 示例2：用户未告知部门

用户：帮我写个关于五一放假安排的通知

输出：
```
XX部通知

各位同事：

根据国家法定节假日安排，现将五一劳动节放假事宜通知如下：

一、放假时间：5月1日至5月5日，共5天
二、上班时间：5月6日（星期一）正常上班
三、注意事项：
   1. 请各部门做好节前安全检查
   2. 值班人员请保持通讯畅通
   3. 外出请注意安全

XX部
2024年X月X日
```

## 注意事项

- 标题格式是硬性要求，绝对不能违反
- 内容要简洁明了，避免冗长
- 重要信息要突出显示
- 时间、地点等关键信息必须明确
