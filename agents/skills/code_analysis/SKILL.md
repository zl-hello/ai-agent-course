# 代码分析技能

## 功能概述

本技能提供代码分析能力，让 Agent 能够：

- 分析代码质量
- 检查潜在错误
- 评估代码性能
- 扫描安全漏洞
- 提供改进建议

## 使用场景

- 代码审查
- 重构建议
- 性能优化
- 安全审计
- 学习最佳实践

## 注意事项

- 支持多种编程语言
- 分析结果仅供参考
- 复杂逻辑需要人工验证
