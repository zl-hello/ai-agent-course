# 网络搜索技能

## 功能概述

本技能提供网络搜索能力，让 Agent 能够：

- 搜索互联网获取最新信息
- 查询新闻和事件
- 查找技术文档和教程
- 获取实时数据

## 使用场景

- 回答需要最新信息的问题
- 查找技术解决方案
- 研究特定主题
- 验证事实信息

## 注意事项

- 需要网络连接
- 搜索结果可能受限于 API 配额
- 注意信息来源的可靠性
